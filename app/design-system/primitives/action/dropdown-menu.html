DropdownMenu

Uses the shared overlay surface, item, separator, and scrolling primitives. Default action menus close immediately on selection.

Staged selection

Set closeOnSelect=false to keep the menu open while changing a draft. Supply footer(close) for Save and Cancel controls beneath the scrollable options. Saving is explicit; Cancel and dismissal never persist changes. The consumer resets draft state when reopening.

Interaction

The trigger exposes expanded state. Items retain keyboard navigation and disabled states. Keep Save disabled while saving or when unchanged; show errors within the open menu. Existing menu behavior is unchanged when these optional props are omitted.
